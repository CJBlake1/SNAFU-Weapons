# SNAFU-Weapons

This contains all of the SNAFU weapons and attachments split into separate types and Expansion Trader files.

As far as I know these are all of the weapons found on the included types file included in the Steam
Workshop mod. I did not look at any of the PBOs.

Each folder has its own Read Me file for instructions

All credit goes to Chimere and the great SNAFU team for creating and maintaining this great mod.
